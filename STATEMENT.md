# Statement

I made this Number Guessing Game in Python as a simple project to practice the things I have learned in Python. The basic idea of the game is that the computer picks a random number and the player has to guess it. The player gets a limited number of chances, so they have to make their guesses carefully.

### What the game has

* There are **3 difficulty levels – Easy, Medium and Hard**.
* In **Easy**, the number range is smaller and the player gets more chances.
* In **Medium**, the number range is bigger and the chances are reduced.
* In **Hard**, the range is bigger again and the player gets fewer chances.
* The game gives **hints** if the player needs some help with the guess.
* The player gets **points** depending on how well they play.
* The **high score** is saved so the player can try to beat their previous score.
* The game also keeps track of the **attempts** made during each game.
* There is a **game history** option where previous game results can be checked.
* It is a **terminal-based game**, so it can be played directly from the command line.

### Why I made it

I made this project for my college assignment and mainly to get more comfortable with Python by making an actual small game instead of just writing separate practice programs.
While making it, I used things like loops, if-else, functions, user input and random numbers. 
It also helped me understand how these basic concepts work together in one project.
